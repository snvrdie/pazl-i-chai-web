# PuzzleMood

Пазлы, судоку, русские сканворды и филворды на русском и английском в браузере. Загрузите свою картинку или выберите встроенный пример, задайте сложность и соберите изображение.

| Уровень | Деталей |
| --- | ---: |
| beginner | 12 |
| easy | 24 |
| medium | 48 |
| hard | 108 |
| advanced | 150 |
| expert | 192 |

Детали лежат в прокручиваемом лотке под полем. Перетащите деталь на стол или выберите её и укажите ячейку в рамке. Подходящие детали соединяются в любой части стола и дальше двигаются вместе. Отдельную деталь или группу можно вернуть в лоток перетаскиванием. На клавиатуре Page Up и Page Down выбирают деталь, стрелки двигают курсор, Enter ставит деталь, а Delete возвращает её в лоток. Масштаб поля меняется кнопками или колёсиком мыши, а стол можно сдвигать за свободное место. Кнопка с процентами возвращает рамку в центр. Кнопка «reference» показывает подсказку, «edges only» помогает начать с рамки, а «sound» включает и выключает щелчок при сборке.

Текущий пазл и библиотека хранятся в IndexedDB в том же браузере. После сборки пазл автоматически попадает в библиотеку. Там можно посмотреть картинку с контурами деталей и скачать исходный файл. Поддерживаются JPG, PNG, WebP, AVIF и GIF до 20 МБ. Для пазла из GIF используется один кадр.

Звук установки детали использует короткий обработанный фрагмент записи [Playing cards on a wooden table](https://freesound.org/people/snuq/sounds/564128/) от snuq, лицензия CC0.

В судоку можно выбрать одну из 36 задач на шести уровнях или пройти их по порядку. Клетки заполняются с клавиатуры или экранной панели. Кнопка «check cell» проверяет выбранную клетку. Кнопка «show solution» открывает решение текущей задачи. Заметки и введённые цифры сохраняются в этом браузере.

В сканвордах вопросы находятся прямо в сетке, а стрелки показывают направление ответа. В серии с кодом пронумерованные клетки дают буквы кодового слова. Кнопка «код» показывает собранные буквы и позволяет проверить их, чтобы открыть следующий выпуск. Сканворд открывается целиком. Кнопки «−» и «+» меняют масштаб, а кнопка с процентами снова вписывает поле в экран. Ввод работает с русской раскладкой физической клавиатуры или клавиатуры телефона. Прогресс и открытые выпуски хранятся в браузере. Е и ё взаимозаменяемы.

В филвордах слова составляются из соседних по стороне букв и могут поворачивать. Выделяйте их перетаскиванием, последовательными нажатиями или клавишами со стрелками и пробелом. Прогресс сохраняется отдельно для каждого поля.

## Совместная игра

Кнопка «играть вместе» открывает новую комнату для выбранного судоку, сканворда, филворда или пазла из галереи. Скопируйте ссылку в комнате и отправьте её второму игроку. По той же ссылке можно вернуться к сохранённой доске. Любой, у кого есть ссылка, может менять её.

## Локальный запуск

Установите Node.js 20 или новее и откройте [http://127.0.0.1:8000](http://127.0.0.1:8000) после запуска сервера.

```sh
npm start
```

Тесты запускаются командой `npm test`.

Для сетевой игры запустите тот же сервер на адресе, доступном обоим игрокам. Для размещения за прокси задайте `HOST=0.0.0.0`, `PORT` и `PUZZLEMOOD_ROOMS_DIR` с путём к постоянному диску. По умолчанию комнаты сохраняются в `.rooms/`. Один экземпляр сервера обслуживает сайт и `/api/rooms` на одном домене. Прокси должен передавать поток событий из `/api/rooms/*/events` по мере поступления.

На статическом хостинге доступны одиночные игры. Для них достаточно разместить `index.html`, `style.css`, `assets/` и `src/` в одной папке. Лицензии шрифтов Cormorant Garamond и Nunito Sans находятся в `assets/fonts/`.
