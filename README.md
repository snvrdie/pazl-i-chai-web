# PuzzleMood

Одиночные пазлы в браузере. Загрузите свою картинку или выберите встроенный пример, задайте сложность и соберите изображение.

| Уровень | Деталей |
| --- | ---: |
| beginner | 12 |
| easy | 24 |
| medium | 48 |
| hard | 108 |
| advanced | 150 |
| expert | 192 |

Детали разложены вокруг рамки. Перетащите деталь на место или сначала выберите её, затем укажите ячейку. На клавиатуре Page Up и Page Down выбирают деталь, стрелки двигают курсор, а Enter ставит деталь. Кнопки масштаба приближают поле, а при увеличении его можно сдвигать за свободное место. Кнопка «reference» показывает подсказку, «edges only» помогает начать с рамки, а «sound» включает и выключает щелчок при сборке.

Текущий пазл и библиотека хранятся в IndexedDB в том же браузере. После сборки пазл автоматически попадает в библиотеку. Оттуда можно открыть изображение и скачать исходный файл. Поддерживаются JPG, PNG, WebP, AVIF и GIF до 20 МБ. Для пазла из GIF используется один кадр.

Звук установки детали использует короткий обработанный фрагмент записи [Playing cards on a wooden table](https://freesound.org/people/snuq/sounds/564128/) от snuq, лицензия CC0.

## Локальный запуск

Установите Python 3 и откройте [http://127.0.0.1:8000](http://127.0.0.1:8000) после запуска сервера.

```sh
python3 -m http.server 8000 --bind 127.0.0.1
```

Для запуска тестов нужен Node.js 20 или новее.

```sh
npm test
```

Для статического хостинга достаточно разместить `index.html`, `style.css`, `assets/` и `src/` в одной папке. Лицензии шрифтов Cormorant Garamond и Nunito Sans находятся в `assets/fonts/`.
